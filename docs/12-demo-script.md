# Two-minute demonstration

Open **https://intent-judge-perfected.vercel.app**. Use a fresh request and **Live Foundry AI**.

1. **The request.** “Book me a nonstop flight from EWR to MCO on 2026-11-12 under $300.” Select **Clarify my request**. Explain that real Foundry inference proposes requirements; it cannot approve a purchase.
2. **The approval.** Show source quotations and the editable rules. Choose any missing preferences deliberately. The shortcut **No preference for unanswered optional details** is an explicit customer choice. Review and approve.
3. **The distinction.** The $295 nonstop offer is intent-checked. The $280 offer has three connections. Native price/product authorization can pass while the approved nonstop requirement fails. A correctly configured VI application could implement this domain extension too; our contribution is the conversational capture, review and reusable domain enforcement.
4. **The gate.** Select **Demonstrate the purchase gate** on the connecting offer. The backend refuses with HTTP 409. Select **Ask Foundry to explain** to get a real AI explanation of checks that already exist; it does not change them.
5. **Specific consent.** Select **Review this difference** and accept the exact nonstop discrepancy. The record binds that value to this signed offer. Confirm a demo booking. Explain that no real payment or reservation occurs.
6. **The evidence.** Download the signed JSON evidence and prepare a dispute review. The final decision belongs to a dispute analyst; no liability protection or chargeback outcome is promised.

For adoption, open a fresh Hotel request. The same engine and workflow check breakfast and free cancellation through another JSON profile. General mode and unsupported baggage/passenger conditions remain held until reviewed evaluators and trustworthy facts support them.

If Foundry is unavailable, the live error is visible. Only deliberately selecting **Emergency offline parser** changes modes. It is labeled and conservative; it is not a substitute for demonstrating live AI.

“Intent Judge translates a natural-language request into customer-reviewed purchasing requirements, binds them into Verifiable Intent, and checks merchant-signed offers with deterministic domain rules. We focus on capturing the right rules before authorization and testing the domain facts afterward.”

The problem figure is **286 million chargebacks**, not $286 million. See [the sourced claim register](02-research-and-claims.md) before using statistics. We have demonstrated specific enforcement behavior, not measured chargeback reduction, industry adoption or legal liability allocation.
